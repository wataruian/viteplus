# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it
privately rather than opening a public issue.

- Use [GitHub's private vulnerability reporting](https://github.com/wataruian/viteplus/security/advisories/new)
  for this repository, or
- Email the maintainer at wiimorata@gmail.com with details of the issue.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof-of-concept if available.
- Any relevant logs, stack traces, or affected versions.

We will acknowledge reports as soon as possible and work with you on a fix
and coordinated disclosure timeline.

## Supported Versions

This repository does not yet follow a formal release/support cycle. Security
fixes are applied to the `main` branch.
